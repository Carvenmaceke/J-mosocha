Set up the website manager

Connect this device once. After that you only need your password.

How to get a GitHub access key
  1. Sign in to GitHub and open Settings → Developer settings → Fine-grained tokens.
  2. Name it “Website manager” and pick an expiry date.
  3. Under Repository access, choose Only select repositories and pick J-mosocha.
  4. Under Permissions → Contents, choose Read and write.
  5. Click Generate token and paste it below.
At least 8 characters.
